## Root Causes Addressed

The Data Integrity backend previously derived verified users from a bounded loaded user array and exposed only the first ten unverified users. The patch obtains an exact unverified Auth total through a filtered Appwrite Users query, derives the verified total from exact Auth and unverified totals, and exposes the ten-row result as an explicit sample with a sample limit and exact-total flag. The 500-user boundary remains applicable to per-user resume ownership/orphan analysis and is disclosed when that analysis is truncated.

Several backend paths converted query exceptions into `{ total: 0 }`, `[]`, or an empty funnel. The patch carries `null` plus safe availability metadata for unavailable metrics, preserves legitimate numeric zeroes, and makes onboarding event-query failures propagate to the panel’s explicit error state.

Premium and Pro counts previously used `effective_plan || legacy plan || 0`, so a legitimate effective-plan count of zero could be replaced by a legacy count. The patch uses `effective_plan` as the authoritative visible count and retains any legacy count only as provenance metadata.

Mission Control previously represented provider pings as general provider health. The patch returns separate transport reachability and stored completion-health snapshots, with provider cards rendering both dimensions. It does not trigger key tests or expose secrets.

The activity response previously labeled the UI `last 50 calls` while the provider-attributed bars summed to only 44. The patch computes the actual returned sample, attributed total, and Unknown/Unattributed rows, and the UI labels the actual population rather than claiming that fifty calls were present.

App Overview and Onboarding previously remained in loading/skeleton states when requests stalled or failures were swallowed. App Overview now has a bounded timeout and terminal error/timeout/empty semantics without visible fake-zero KPI fallbacks. Onboarding now has bounded loading, error, timeout, empty, and success paths.
